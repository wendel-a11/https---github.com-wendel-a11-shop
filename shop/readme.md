# ShopFlex – Sistema de Gerenciamento de Loja Virtual

## Objetivo
Desenvolver um sistema web para apoiar o gerenciamento de uma pequena loja virtual, permitindo organizar clientes, produtos, categorias, funcionários, pedidos, itens dos pedidos, pagamentos e entregas.

## Tecnologias utilizadas
- HTML5: estrutura das páginas.
- CSS3: identidade visual, layout responsivo e tema escuro.
- JavaScript: navegação, validações e operações CRUD.
- LocalStorage: armazenamento local dos dados no navegador nesta versão acadêmica.
- Git e GitHub: controle de versão e organização do desenvolvimento.

## Como executar
1. Baixe ou clone este repositório.
2. Abra a pasta `ShopFlex`.
3. Abra o arquivo `index.html` em um navegador atualizado.
4. Não é necessário instalar servidor ou banco de dados para esta demonstração.

## Funcionalidades desenvolvidas
- Painel com resumo de produtos, clientes, pedidos e valor dos pedidos.
- CRUD de clientes, produtos, categorias, funcionários, pedidos, itens do pedido, pagamentos e entregas.
- Pesquisa de registros em cada módulo.
- Validação de campos obrigatórios e prevenção de CPF, e-mail e código de produto duplicados.
- Validação de subtotal dos itens do pedido.
- Mensagens de sucesso e erro.
- Armazenamento local com LocalStorage.
- Layout responsivo e tema escuro.

## Observações
Esta é uma versão de demonstração front-end. O LocalStorage guarda os dados somente no navegador e não substitui um banco de dados compartilhado. A modelagem e implementação em MySQL serão desenvolvidas no trabalho de Modelagem de Banco de Dados.
